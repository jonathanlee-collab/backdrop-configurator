BACKDROP V1 CONFIGURATOR

Files:
- index.html
- styles.css
- app.js

How to run:
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome/Edge/Safari.
3. No Node.js, database, or server is required for V1.

Optional local server:
If Python is installed, open Command Prompt in this folder and run:
  python -m http.server 3000
Then visit:
  http://localhost:3000

Important V1 notes:
- Prices and products are sample catalogue values.
- WhatsApp opens with a prefilled enquiry summary; no fixed phone number is hardcoded yet.
- No inventory availability, payment, admin dashboard, or database is included yet.
- Replace sample product names/prices after the prop audit.
